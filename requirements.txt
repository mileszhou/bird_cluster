# Pinned snapshot of a known-good environment. NOT the install path.
#
#     ./venv                       <- the install path, and the ground truth
#     pip install -r requirements.txt   <- only when versions have drifted
#                                          far enough to break something
#
# Regenerate with `./venv freeze` after a deliberate upgrade, never as a
# side effect. `./venv` decides what is installed; this records what that
# produced, so the two can disagree only until someone re-freezes.
#
# Frozen on Linux/aarch64, Python 3.12.3, 2026-08-26.
# Portable on purpose. pip freeze reports torch by version alone, without
# the +cuNNN local tag it was built with, so these pins resolve against
# plain PyPI and each machine gets the build matching its own platform.
# Transitive nvidia-*/triton wheels are dropped for the same reason: torch
# pulls the right ones for the CUDA it finds, and pinning the set from
# this box would make the file installable only on a box exactly like it.
#
# This is what is *installed*, which is a superset of what ./venv installs
# if anything was ever pip-installed by hand. Check a diff before
# committing a re-freeze, the same as any other generated file.
#
